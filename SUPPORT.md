# Getting help

Fedimint Card is an experimental open source project. Help comes from its maintainers on a
best-effort basis.

- **Bugs and questions:** open an issue in the repository it concerns.
- **Vulnerabilities:** report them privately, as [SECURITY.md](SECURITY.md) describes.
- **Anything else:** [hi@fedimintcard.org](mailto:hi@fedimintcard.org).
- **Fedimint itself:** see [fedimint.org](https://fedimint.org).
